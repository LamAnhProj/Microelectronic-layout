# Codex desktop shortcuts on this Mac

The engineer confirmed this recovery sequence worked on 2026-11-14.

| Action | Mac shortcut |
| --- | --- |
| Reopen the tab just closed, including a side-chat tab | **⌘ ⇧ T** |
| Open the side-chat control from the current Codex chat | **⌘ ⌥ S** |

Try **⌘ ⇧ T** first after accidentally closing a side chat. **⌘ ⌥ S**
opens side chat from the current chat; it is not a substitute for recovering
the exact closed tab.

Source: [OpenAI desktop commands](https://learn.chatgpt.com/docs/reference/commands).
